== curl

[source,bash]
----
curl/03-fetch.sh folder /
curl/03-fetch.sh document "/Invoices/invoice.pdf"
curl/03-fetch.sh document "{4D0B1E8B-0000-C61A-9A5B-2C5D1B6E3F11}"
----

== Java

[source,bash]
----
cd java && mvn -q compile exec:java -Dexec.args="fetch folder /"
----

See `Examples#document` and `Examples#folder`.

== Notes

Large folders return their children in pages. Request only the fields you need.
