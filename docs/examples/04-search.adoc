= Search

The `documents` query runs a FileNet search. `from` is the class to search, `where` is a SQL-like condition on its properties.

== curl

[source,bash]
----
curl/04-search.sh "DocumentTitle LIKE 'Invoice%'"
curl/04-search.sh "This INFOLDER '/Invoices'"
----

[source,bash]
----
cd java && mvn -q compile exec:java -Dexec.args="search \"DocumentTitle LIKE 'Invoice%'\""
----

See `Examples#searchDocuments`.

== Notes

* Useful conditions: `DocumentTitle LIKE '...'`, `This INFOLDER '<path-or-id>'`, `DateCreated > 20240101T000000Z`.
* `pageInfo.token` is a continuation token for the next page of a large result.
* Quote string values with single quotes and escape quotes inside them by doubling them.
