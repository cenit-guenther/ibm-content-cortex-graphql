= Introspection

GraphQL describes itself. Use introspection to learn which types and fields your FileNet version offers. This is the best first call: it needs no object store and tells you whether endpoint, credentials and TLS are working.

== Java

[source,bash]
----
cd java && mvn -q compile exec:java -Dexec.args="introspection [TypeName]"
----

See `Examples#schemaOverview` and `Examples#typeDetails` in `java/src/main/java/io/github/filenet/graphql/examples/Examples.java`.

== Notes

The response lists, for example, `Document`, `Folder` and `ContentTransfer`. Use the type details to check property names before you adapt the other examples.
