= Create a document with content upload

FileNet uploads use a `multipart/form-data` request. The mutation declares the content variable as `String`; its value is the name of the file part that carries the bytes.

== Request layout

[source,text]
----
POST /content-services-graphql/graphql
Content-Type: multipart/form-data; boundary=...

--...  name="operations"   {"query":"mutation CreateDocument(...)","variables":{...,"file":"file1"}}
--...  name="file1"; filename="hello.txt"; Content-Type: text/plain   <file bytes>
----

== Java

[source,bash]
----
cd java && mvn -q compile exec:java -Dexec.args="upload ./hello.txt /demo"
----

`FileNetClient#executeUpload` builds the multipart body with plain `java.net.http`; see `Examples#createDocument`.

== Notes

* `fileInFolderIdentifier` files the document into a folder; `checkinAction: {}` checks it in immediately.
* The variable `file` contains the part name `file1`; the content of that part becomes the document content (`subContentTransfer.content`).
