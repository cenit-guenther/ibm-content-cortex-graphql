= Check out, check in and versions

Checking out a document creates a reservation (a working copy). Checking it in turns the reservation into a new version.

== curl

[source,bash]
----
curl/09-versioning.sh checkout "{DOCUMENT-ID}"    # the response contains the reservation id
curl/09-versioning.sh checkin  "{RESERVATION-ID}"
curl/09-versioning.sh versions "{DOCUMENT-ID}"
curl/09-versioning.sh cancel   "{RESERVATION-ID}"
----

[source,bash]

== Java

[source,bash]
----
cd java && mvn -q compile exec:java -Dexec.args="versioning checkout {DOCUMENT-ID}"
----

See `Examples#checkout`, `Examples#checkin`, `Examples#cancelCheckout` and `Examples#versions`.

== Notes

Check in and cancel operate on the *reservation id* (`reservation { id }` in the checkout response), not on the id of the released version. The `checkoutDocument` response itself describes the released version.
